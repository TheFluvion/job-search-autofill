CV Autofill

Cómo usar

1. Configurar la IA

  1. Abrí Configuración IA.
  2. Elegí proveedor (Gemini, Claude o ChatGPT) y pegá tu API key.

Si no sabés cómo obtener la API key de Gemini, Claude o ChatGPT, hacé click en los nombres.

  1. Revisá el modelo (por defecto la versión gratis/barata de cada uno) y tocá Guardar.

Listado de modelos disponibles: Gemini, Claude, ChatGPT (OpenAI).

2. Cargar el CV

  1. Elegí un PDF del CV y tocá Parsear CV.
  2. Revisá el JSON del perfil, editá si hace falta y tocá Guardar perfil.

También se leen hipervínculos del PDF (LinkedIn, GitHub), aunque estén detrás de íconos.

3. Llenar el formulario

  1. Abrí la página del formulario de postulación.
  2. Tocá Llenar. Escanea campos, agrega bloques si hace falta y mapea por pasos.
  3. Si la IA está saturada, reintenta sola y muestra el progreso.

4. Revisar el reporte

  • Verde: llenado OK.
  • Amarillo: baja confianza (revisalo).
  • Rojo: no se pudo llenar.

Click en un ítem para ir al campo. En formularios multi-paso, tocá Llenar en cada pantalla.

Limitaciones

  • Captchas, algunos iframes y subida de archivos.
  • Campos personales (salario, motivación, DEI) quedan sin llenar a propósito.

Template de CV

En el repo está cv_template_spanish.html para adaptar.

  1. Editá el HTML con tus datos.
  2. Abrilo en el navegador.
  3. Usá Ctrl+P (Cmd+P en Mac).
  4. Elegí Guardar como PDF (no “Print to PDF” del sistema: suele romper links).
  5. Usá ese PDF en la extensión.

Usá siempre Guardar como PDF del navegador para no perder LinkedIn/GitHub.
